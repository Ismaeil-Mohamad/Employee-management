# Employee Management System

## About the Project

A simple Java project for managing employee records. This project was created to practice Java programming, input validation, exception handling, and unit testing.

## Features

- Add employees.
- Find employees by ID.
- Retrieve all employees.
- Count employees.
- Prevent duplicate employee IDs.
- Validate employee IDs, names, and salaries.
- Handle invalid input using `IllegalArgumentException`.

## Technologies

- Java
- Maven
- JUnit 5

## Unit Tests

The project includes tests for:

- Adding an employee.
- Finding an employee by ID.
- Rejecting a negative salary.
- Rejecting duplicate employee IDs.

## Run Tests

Run the following command from the project root directory:

```bash
mvn clean test
```
